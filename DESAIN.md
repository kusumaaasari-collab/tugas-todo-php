# Desain Antarmuka Aplikasi Todo List PHP

## Tujuan Desain
Desain antarmuka aplikasi Todo List ini dibuat untuk memberikan tampilan yang sederhana, bersih, serta mudah digunakan oleh pengguna. Fokus utama dari desain ini adalah kemudahan dalam menambahkan, melihat, dan menghapus daftar tugas.

## Konsep Desain
- Minimalis dan sederhana
- Mudah dipahami oleh pengguna pemula
- Responsif untuk berbagai ukuran layar
- Mengutamakan kenyamanan pengguna (user friendly)

## Teknologi Desain
- HTML
- CSS
- Bootstrap 5

## Struktur Desain Halaman
Halaman utama aplikasi terdiri dari beberapa bagian utama, yaitu:
1. Judul aplikasi
2. Form input untuk menambahkan tugas
3. Daftar tugas
4. Tombol aksi (Tambah dan Hapus)

## Komponen UI
### 1. Form Input Tugas
Digunakan untuk menambahkan tugas baru ke dalam daftar.
- Input text untuk nama tugas
- Tombol tambah dengan warna utama (primary)

### 2. Daftar Tugas
Menampilkan daftar tugas yang telah ditambahkan.
- Menggunakan tampilan list
- Setiap tugas ditampilkan dalam satu baris

### 3. Tombol Aksi
- Tombol **Tambah** untuk menambahkan tugas
- Tombol **Hapus** untuk menghapus tugas
- Warna tombol disesuaikan dengan fungsinya agar mudah dipahami

## Warna dan Tampilan
- Background halaman menggunakan warna terang
- Warna tombol disesuaikan dengan standar Bootstrap
- Font sederhana agar mudah dibaca

## Responsivitas
Desain aplikasi sudah responsif dengan memanfaatkan class dari Bootstrap, sehingga dapat diakses dengan baik melalui desktop maupun perangkat mobile.

## Catatan Pengembangan
Desain ini masih dapat dikembangkan lebih lanjut, seperti:
- Penambahan fitur edit tugas
- Penandaan tugas selesai
- Animasi ringan untuk interaksi pengguna
